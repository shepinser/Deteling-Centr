# Детейлинг-центр

Первая рабочая версия приложения: клиенты, менеджеры, мастера, услуги и заказы. Доступны добавление, удаление, сохранение и поиск.

## Ветки

- `V1` — первая рабочая версия.
- `V2-ITOG` — вторая версия: регистрация, вход по ролям, автомобили клиентов, оформление заказов и отзывы.

## Запуск первой версии

Открыть `Детейлинг 1/WindowsFormsApp1.slnx` в Visual Studio и нажать F5.
Требуются .NET Framework 4.8 и Microsoft ACE OLEDB. Для Windows x64 используется 64-разрядный провайдер Access.

Готовая сборка: распаковать `Детейлинг 1.zip` целиком и запустить `WindowsFormsApp1.exe`.
База `Database61.accdb` должна находиться рядом с EXE.
