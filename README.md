# Детейлинг-центр

Первая версия интерфейса на C# Windows Forms с базой Microsoft Access.

- `V1` — исходная первая версия.
- `V2-ITOG` — доработанная версия с регистрацией, ролями, автомобилями и заказами.

Проект первой версии: `Детейлинг 1/WinFormsApp1.slnx`.
Файлы исходной версии сохранены без исправления ее кода.
