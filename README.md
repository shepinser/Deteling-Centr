# Детейлинг-центр

Первая рабочая версия приложения: клиенты, менеджеры, мастера, услуги и заказы. Доступны добавление, удаление, сохранение и поиск.

## Ветки

- `V1` — первая рабочая версия.
- `V2-ITOG` — вторая версия: регистрация, вход по ролям, автомобили клиентов, оформление заказов и отзывы.
