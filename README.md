# Детейлинг-центр

Учебное настольное приложение на C# Windows Forms и Microsoft Access.

## Версии

- `V1` — исходная первая версия интерфейса.
- `V2-ITOG` — итоговая версия приложения.

## Возможности

Регистрация и вход клиента и администратора, учет автомобилей, выбор услуг и оформление заказов, назначение мастера, изменение статуса, оценки и отзывы. Администратор ведет справочники клиентов, администраторов, мастеров и услуг.

## Запуск

1. Открыть `Детейлинг 2/WinFormsApp1.slnx` в Visual Studio с поддержкой .NET 10 и Windows Forms.
2. Дождаться восстановления пакетов NuGet и нажать F5.

Требуются Windows x64, .NET 10 и Microsoft ACE OLEDB x64. База проекта: `Детейлинг 2/БД/бд.accdb`.

Учебные аккаунты:

- администратор: `admin1` / `admin123`;
- клиент: `client1` / `client123`.

Кнопка «Оплатить и оформить» подтверждает оформление учебного заказа; банковских переводов приложение не выполняет.

## Документы

- `Руководство пользователя Детейлинг.docx` — руководство по работе с приложением;
- `Детейлинг Центр.mdj` — ранее подготовленная модель бизнес-процесса. Выбор времени и боксов из модели в этой версии программы не реализован.
